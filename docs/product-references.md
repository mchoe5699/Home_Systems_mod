## 확인한 공식 PDF 설명서

- [로비폰 DRC-707LC 설명서](https://www.commax.com/DATA/board/KOREAN_manual/data/20221223172822287_MJEzIIJg.pdf): 세대 호출, 동 로비/외곽 로비의 입력 순서, 경비실 호출을 확인했습니다.
- [월패드 CAV-1000YD 설명서](https://www.commax.com/DATA/board/KOREAN_manual/data/20230102164721962_mlMYLCCb.pdf): 터치 조작과 현관·경비실·제어 화면 구성을 확인했습니다. 일부 PDF 글꼴의 텍스트 추출이 깨져 도해와 제품 사진을 함께 참고했습니다.
- [경비실기 CDS-70M 설명서](https://www.commax.com/DATA/board/KOREAN_manual/data/20221130174929552_gnyRGRGe.pdf): 수화기·숫자 키, 통화 화면, 수화기를 들어 받는 동작, 종료와 문열림을 확인했습니다.

비디오폰·인터폰은 위 공식 제품 사진과 기능 설명을 확인했으며, 해당 모델의 별도 PDF를 확보했다고 주장하지 않습니다. 실제 로비폰·경비실기의 출입 인증·PSTN·주차·택배·비상·방문자 저장 등은 이번 기본 구현의 기능에 포함하지 않습니다. 실제 제조사 모델의 배선 규격을 모드의 STAR/BUS 설정과 동일하다고 간주하지 않습니다.

## 모드에서 적용하는 규칙

- 음성 역할은 채팅 통화입니다. 수화기선은 모든 기기에서 생략합니다.
- 수화기를 누르면 들기/놓기를 전환합니다. 호출 수신 중 들면 응답하고, 놓으면 양쪽 통화를 끝냅니다. 들고 놓인 상태는 월드의 실제 블록 모델로 동기화합니다.
- 모니터가 있는 기기는 자기 세대에 홈 링크된 도어카메라를 30초 동안 확인할 수 있습니다. 도어폰에서는 영상이 나오지 않으며, 모니터 확인 자체는 채팅 통화를 시작하지 않습니다.
- 실제 영상 화면과 표시등은 주변 플레이어에게도 보입니다. 다른 단지의 영상과 외부 블록은 전송하지 않으며 원격 청크를 강제로 로드하지 않습니다. 클라이언트의 동시 외부 모니터 캐시는 최대 8개입니다.
- 통신 방식은 기존 월드 호환을 위해 기본 STAR이며 설정 화면에서 BUS로 바꿀 수 있습니다. 같은 방식끼리만 호출·홈 링크·모니터 확인·경비실 우회를 허용합니다. 제조사 모델명을 확정한 제품의 통신 규격은 제공 자료에 맞춰 별도 고정할 수 있습니다.
- 로고는 각 제품의 별도 PNG 리소스로 분리했습니다. [로고 교체 안내](logos.md)를 참고하세요.
