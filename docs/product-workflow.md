# 실제 제품 제작 시 유지할 요구사항

이 문서는 사용자가 정한 후속 제품 제작 기준입니다. 아래 기준 전체가 현재 기본 기기에 구현되었다는 뜻은 아닙니다. 제품 사진·설명서·모델명이 제공되면 모델별로 구현하고 검증합니다.

- `월패드 생성` 등 제품 생성 요청에는 설명 없이 해당 제품의 빈 제품 제원 및 요구사항 양식을 먼저 응답합니다. 사용자가 요청서·여러 장의 사진·PDF를 보낸 다음 제작합니다.
- 실제 제품 모델의 사진 기준으로 형태·색상·버튼 위치·화면 배치를 재현합니다. 확인할 수 없는 부분은 임의로 만들지 않습니다. 제품마다 형제모델·색상·타입 여부를 요청서에서 확인합니다.
- 수화기가 있는 모든 제품에서 **수화기선은 생략**합니다. 수화기를 들었을 때와 내려놓았을 때를 각각 구현하며 다른 플레이어도 월드에서 그 변화를 볼 수 있어야 합니다.
- 모든 제품의 로고는 사용자가 제공하는 PNG/SVG로 교체할 수 있어야 합니다. 제품 사진의 위치·크기를 따르며 조작 화면에 있는 로고도 대상으로 합니다.
- 제품 우클릭 시 제품과 같은 조작 화면이 열리고 조작 결과가 외부 제품의 화면·표시등·수화기 등에도 반영되어야 합니다.
- 통화의 음성 역할은 채팅으로 유지합니다. 도어카메라는 영상+채팅, 도어폰은 채팅만 사용합니다.
- 같은 단지 안에서도 **STAR는 STAR끼리, BUS는 BUS끼리만 연동**해야 합니다. 형제모델 전환으로 이 제한을 우회해서는 안 됩니다. 1.6.0 기본 기기는 설정 화면에서 STAR/BUS를 선택하고 서버가 일치 여부를 검사합니다. 특정 실제 모델의 통신 방식 고정은 제품 자료에 맞춰 적용합니다.
- 로비폰·인터폰·비디오폰·월패드 조작 화면에는 관할경비실 및 세대번호(동·호) 설정 버튼 **하나**가 있어야 합니다. 각 번호 0~9999를 직접 입력 후 저장합니다. 경비실기는 경비실번호 설정 버튼으로 0~9999를 입력 후 저장합니다.
- 기존 단지 경계·관할 경비실 우선·명시적 부재/외출 시에만 다른 경비실 우회·로비폰 동 9999·도어 링크·홈 링크 및 홈 네트워크 규칙을 유지합니다.
- 형제모델 선택기 목록은 요청서에 적힌 실제 형제모델과 제공된 자료를 기준으로 채웁니다. 샘플 또는 다른 종류의 기기를 실제 형제모델이라고 등록하지 않습니다.

1.6.0에서는 사용자가 직접 인터넷 사진·설명서 조사를 승인하여 공식 제품 자료로 기본 5종을 재제작했습니다. 참고 출처·구현 범위·실제 검증 화면은 product-references.md에 기록했습니다. 이후 사용자 제공 자료에 따른 개별 제품 제작 요청은 계속 적용합니다.
