# 기기 8종 곡면 처리 — 1.9.0

로비폰·비디오폰·인터폰·월패드·경비실기·도어카메라·도어폰·SHT-308에 공통 적용했습니다.

- 본체를 작은 상자로 겹쳐 쌓던 방식을 제거하고, 이어진 면과 부드러운 표면 법선으로 둥근 모서리를 그립니다. 겹친 면의 깜빡임과 조각 경계가 생기지 않게 구성했습니다.
- 수화기는 코드선 없이 이어진 곡면으로 그립니다. 들기/거치 상태를 유지하며, SHT-308의 받침·걸쇠·스피커·버튼과 검은 화면 테두리도 같은 방식으로 처리합니다.
- 경비실기의 물리적 숫자 키와 문열림 키는 높이가 있는 곡면입니다. 참고 제품의 평평한 터치/인쇄 버튼을 임의로 돌출시키지 않습니다.
- 월드·인벤토리·손에 든 아이템에서 같은 형상 캐시를 사용합니다. 매 프레임 새 모델을 만들지 않습니다. 형상 변경은 기기의 저장된 번호·연동과 별개입니다.
- 조작 화면의 전면 텍스처는 큰 원본에서 그린 뒤 축소해 곡선 가장자리를 정리했습니다. 도어카메라·도어폰은 기존 저해상도 확대 텍스처를 새로 그렸습니다.
