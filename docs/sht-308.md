# 삼성 SHT-308 비디오폰 — 1.8.0

사용자가 제공한 **제품 정면·측면·수화기 분리 사진과 SHT-308.pdf(20쪽)**를 기준으로 기존 SHT-308 외형을 교체한 제품입니다. 기존 기본 비디오폰을 대체하지 않습니다. 아이템 ID는 `homesystems:sht_308`이며 크리에이티브 홈시스템 탭과 서바이벌 조합을 지원합니다.

## 적용한 제품 제원

| 항목 | 적용 내용 |
| --- | --- |
| 제품·제조사 | 삼성 SHT-308 |
| 통신 | 사용자 요청에 따라 **BUS 고정**. 설정 화면·서버 요청·저장 데이터로 STAR로 바꿀 수 없습니다. |
| 영상 | 실제 카메라 영상을 흑백 명도 영상으로 변환. 조작 화면과 월드의 CRT 모두 동일합니다. |
| 조작 | 버튼·수화기·측면 전원/음량과 하단 밝기/명암 스위치 |
| 수화기 | 요청서의 수화기 있음 사양 적용. 들기/놓기 모델을 각각 구현하고 **수화기선은 생략**합니다. |
| 외형 | 아이보리 본체, 왼쪽 수화기와 거치대·스피커, 위쪽 브라운관과 오른쪽 스피커, 세로 4개 버튼 |
| 로고 | 사진과 PDF의 SAMSUNG 위치. 별도 `textures/logo/sht_308.png`로 교체 가능 |
| 타입 | 추가 타입 없음 |
| 형제모델 | SHT-312·SHT-305·SHT-305V·SHT-307은 사용자 요청대로 **추후 제작**. 현재 다른 모델의 외형을 대신 넣어 선택 가능하다고 표시하지 않습니다. |

사용자가 제공한 원본 사진·PDF는 배포 JAR/공개 저장소에 복사하지 않았습니다. 제품을 참고해 제작한 텍스처·3D 모델과 모드 안에서 촬영한 검증 화면만 포함합니다. 사진의 원근·반사·노후 흔적을 그대로 붙인 평면 장식이 아니라, 거치대와 분리되는 수화기·돌출 버튼을 가진 Minecraft 모델입니다.

## 1.8.0 재제작

이전 SHT-308 모델·텍스처를 새 리소스로 교체했습니다. 본체의 둥근 테두리와 깊이, 검은 화면 테두리의 돌출, 안쪽에 들어간 브라운관, 수화기의 연속 곡면 단면, 수화기를 들었을 때 드러나는 걸쇠·가로 스피커·받침을 다시 구성했습니다. 같은 아이템 ID를 유지하므로 기존 설치 위치와 저장한 번호·링크를 지우지 않고 새 모습으로 바뀝니다. 사진의 촬영 각도·조명에 따른 반사까지 동일한 사진 복제는 아니며 Minecraft 안의 입체 모델입니다.

## 사용 준비

1. 단지 대시보드로 설치 위치를 포함하는 구획을 만듭니다.
2. SHT-308을 설치하고 우클릭합니다.
3. 기존 공통 **관할경비실 및 세대번호(동·호) 설정** 버튼 하나에서 각각 0~9999를 입력한 뒤 저장합니다. 이 모드의 공통 번호 규칙이 PDF의 물리적 8개 DIP 스위치를 대신합니다.
4. 연결할 도어카메라/도어폰·로비폰·경비실기도 BUS로 설정합니다. STAR 기기는 같은 단지여도 연결되지 않습니다.
5. **홈 링크**로 SHT-308을 선택한 뒤 도어카메라/도어폰을 연결합니다. 도어폰은 채팅 통화만 가능하고 영상은 없습니다.

## 실제 제품 전면 조작

오른쪽 버튼은 위에서부터 **비상 → 경비실 → 외출 → 현관**입니다. 각 버튼에 마우스를 올리면 기능이 표시됩니다.

- **수화기:** 수신 중 들면 응답합니다. 내려놓으면 양쪽 통화와 영상이 종료됩니다. 수화기를 든 상태와 거치된 상태는 다른 플레이어에게도 보입니다. 들어 올린 수화기를 다시 클릭하거나 거치대를 클릭하면 내려놓습니다.
- **현관 확인:** 대기 중 현관 버튼을 누르면 홈 링크된 도어카메라의 흑백 영상이 켜집니다. 다시 누르거나 **15초**가 지나면 꺼집니다. 영상 확인만으로 채팅 통화를 시작하지 않습니다. 확인 중 수화기를 들면 현관과 채팅 통화가 연결됩니다.
- **현관 수신:** 방문자가 연결된 도어카메라/도어폰에서 호출하면 수화기로 응답합니다. 도어카메라는 수신 즉시 흑백 영상이 나오며, **15초** 이내 응답하지 않으면 이 SHT-308의 수신이 종료됩니다. 같은 세대의 다른 기기는 각자 규칙에 따라 계속 울릴 수 있습니다.
- **현관 통화:** 현관과의 통화는 **1분**입니다. 통화 중 현관 버튼을 누르면 통화 시간을 다시 1분으로 연장합니다.
- **경비실:** 먼저 수화기를 들고 경비실 버튼을 누릅니다. 관할 경비실을 우선 호출하며, 경비실 수신 때는 해당 램프가 깜박이고 연결되면 켜집니다. 경비실 통화 자체로 CRT를 켜지 않습니다. 종료는 수화기를 놓습니다.
- **공동현관 문열기:** 로비폰과 연결된 통화 중 현관 버튼을 누르면 그 로비폰의 도어 링크 문을 엽니다. **연결되지 않은 상태에서는 열리지 않습니다.** 이 모델에서 개별현관 통화 중 같은 버튼은 통화 연장용이며, 대기 중 사설 문을 여는 별도 버튼은 추가하지 않았습니다.
- **외출:** 외출 버튼을 누르면 램프가 켜집니다. 방문자가 연결된 도어카메라/도어폰을 누르면 세대와 호출 가능한 경비실을 함께 울리고 먼저 응답한 쪽이 통화를 받습니다. 관할 경비실이 우선이며, 기존 규칙대로 등록된 관할 경비실들이 모두 명시적으로 부재/외출일 때만 다른 경비실로 우회합니다. 단순 통화 중·미등록·청크 미로딩은 우회 사유가 아닙니다. 우회 수신은 15초, 연결된 우회 통화는 1분입니다. 외출을 해제하면 해당 외출 설정을 근거로 연결된 우회 통화도 종료합니다.
- **비상:** 비상 버튼으로 켜고 같은 버튼으로 해제합니다. PDF 순서에 따라 내부 경보 30초 → 관할 경비실 통보와 연결된 현관 기기의 경보 1분 → 해제할 때까지 내부 경보를 반복합니다. 같은 단지·BUS·관할 경비실에만 비상 알림을 보냅니다. 경비실에는 알림과 비상 건수가 표시됩니다. 이는 게임 안의 알림이며 외부 전화나 실제 신고가 아닙니다.
- **전원:** 수화기 거치대 옆 작은 전원 스위치를 클릭합니다. 꺼지면 통화·영상·경보를 중지하고 새 호출을 받지 않습니다. 전원을 꺼도 수화기 자체를 드는 모습은 바꿀 수 있습니다.
- **음량·밝기·명암:** 오른쪽 위 측면의 음량, 본체 아래의 밝기/명암 스위치의 원하는 위치를 클릭하거나 끌어서 소·중·대 세 단계를 선택합니다. 음량은 위쪽이 크게, 밝기·명암은 오른쪽이 높게 설정됩니다. 키보드로 버튼을 작동하면 단계가 순환합니다. 밝기와 명암은 실제 흑백 픽셀에 적용되고 외부 화면에도 반영됩니다. 설정은 저장됩니다.

일반 대화의 음성 역할은 기존 요청대로 **채팅**입니다. 다른 단지로 연동하거나 원격 청크를 강제로 로드하지 않습니다. 외출·경보·전원·조절 설정은 재시작 후 유지하며, 통화와 잠깐의 영상 확인 세션은 다시 시작하지 않습니다.

## 검증

- Forge 전용 GameTest 서버: 필수 테스트 **41개 통과**. SHT-308의 BUS 고정·흑백 변환·15초 확인·1분 통화 연장·외출 우회·비상 단계·공동현관 문열기·스위치 저장과 잘못된 값 거부를 포함합니다.
- 실제 Minecraft 클라이언트: 번호 입력·저장, 실제 위젯 클릭, 흑백 영상 픽셀, 수화기 응답/종료, 월드 CRT, 경비실 표시등, 외출 우회, 실제 철문 열림, 30초 후 비상 통보 및 해제를 확인했습니다.
- 수정한 화면에서 스위치를 실제로 드래그해 최종 위치가 서버 설정에 반영되는 것까지 확인했습니다.
- 배포 JAR는 테스트용 자동 조작 코드를 제외하고 다시 빌드합니다. 서버와 클라이언트 모두 1.8.0으로 업데이트해야 합니다.
