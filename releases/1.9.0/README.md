# Home Systems 1.9.0

Minecraft Java 1.20.1 / Forge 47.4.0 이상(47.x) / Java 17

기기 8종의 본체·수화기·물리 버튼을 이어진 곡면으로 처리하고, 설치된 제품과 아이템에 같은 형상을 적용했습니다. 겹친 상자들의 이음새를 제거하고, 전면 그림 가장자리를 정리했습니다. 공식 제원을 확보한 기본 기기는 두께 비율도 다시 반영했습니다.

SHT-308은 제공된 사진/PDF를 기준으로 받침·걸쇠·화면 테두리·버튼까지 곡면으로 처리했습니다. 기본 경비실기는 받침 비율과 물리 OPEN 버튼 위치를 조정했습니다. 세대 입력 후 #로 호출하고, 원형 OPEN으로 통화 중인 로비의 문을 엽니다.

검증: 필수 GameTest 41개 모두 통과. 실제 클라이언트에서 기기 8종의 월드·아이템·조작 화면과 수화기 4종의 입력을 확인했습니다. 실제 카메라 영상과 OPEN을 이용한 철문 개방도 확인했습니다. 배포 JAR에는 자동 조작 테스트 코드가 포함되지 않습니다.

기존 홈시스템 JAR를 제거하고 서버와 클라이언트 모두 1.9.0을 설치하세요. 기기 번호와 링크는 유지됩니다.
