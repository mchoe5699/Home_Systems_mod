# Home Systems 1.8.0

Minecraft Java 1.20.1 / Forge 47.4.0 이상(47.x) / Java 17

기존 SHT-308의 외형을 제공된 정면·측면·수화기 분리 사진에 맞춰 교체했습니다. 곡면 수화기, 거치대와 스피커, 돌출된 검은 화면 테두리와 버튼을 구현했습니다. 호출 음량·밝기·명암은 실제 3단계 슬라이더로 선택하고 저장합니다.

BUS 고정·흑백 영상·채팅 통화·공통 번호 설정, PDF의 15초 현관 확인·1분 통화 연장·외출 우회·비상 단계·공동현관 문열기를 지원합니다. SHT-312·SHT-305·SHT-305V·SHT-307은 추후 제작 대상입니다.

필수 GameTest 41개 통과. 실제 클라이언트에서 통화·영상·문·경보·스위치 클릭 및 드래그와 들기/놓기 외형을 확인했습니다. 배포 JAR에는 테스트 자동 조작 코드를 포함하지 않습니다.

이전 JAR를 제거하고 서버와 모든 클라이언트에 같은 1.8.0 JAR를 설치하세요. 기존 SHT-308의 번호와 링크는 유지됩니다.
